## 🎮 What’s This Project?

Guess The Word is a sleek, responsive word-guessing game:

* You’re given a hidden word.
* You guess letters (or perhaps the full word).
* You receive feedback.
* You win when you uncover the word — all wrapped in a refined UI.

It’s part game, part aesthetic practice — because even simple logic deserves to *feel good*.

---

## ✨ Features You’ll Notice

* 📌 Hidden-word display (underscores, blanks, or placeholder) → guess to fill in.
* 👀 Visual feedback each guess: correct letters revealed, mistaken ones maybe flagged.
* 📏 Score/trial count or attempt-limit (as you’ve designed it) adds challenge.
* 🎨 Thoughtful UI: layout, typography, spacing that say “yes, this is built with care”.
* 📱 Fully responsive: works gracefully across mobile, tablet and desktop.
* 🛠 Built with simple, clean code (HTML + CSS + JS) — reliable, readable, yours.

---

## 🧠 Tech Stack

| Technology     | Role                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------ |
| **HTML**       | Structure of the game board: hidden word, input area, control buttons                      |
| **CSS**        | Styling the word display, feedback states, responsive design                               |
| **JavaScript** | Game logic: selecting the secret word, capturing guesses, updating display, win/loss logic |
